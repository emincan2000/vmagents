Yapay zeka asistanlarını bilgisayarında değil, bir VM'de çalıştır.

vmforai; Claude Code, Codex, Gemini CLI, OpenCode ya da aider'ı tek komutla bir sanal makinenin içinde çalıştırır. Asistan istediğini kurabilir, çalıştırabilir, bozabilir. Her başlatmada önce bir anlık görüntü alınır; vmforai undo hepsini geri alır.

# Linux (Debian, Ubuntu, Arch, Fedora, openSUSE, Alpine)
curl -fsSL https://raw.githubusercontent.com/emincan2000/vmforai/main/install.sh | bash
vmforai create dev   # içinde Claude Code olan yeni bir Debian VM
vmforai dev          # VM'de çalışan Claude Code

Neden bir VM?

Asistan sormadan çalışabilir

Orada rm -rf, dikkatsiz bir sudo ya da bozuk bir paket yalnızca VM'i bozar ve tek komutla geri alınır.

İçinde senin hiçbir şeyin yok

SSH anahtarın, tarayıcın, GitHub token'ın yok. Bir depo kopya olarak girer; asistanın işi bir git dalı olarak geri gelir.

Konteyner değil, koca bir bilgisayar

Kendi çekirdeği, systemd, Docker, istersen bir masaüstü. Windows VM'leri de olur.

Sen yokken de devam eder

Görevler arka planda çalışır. Terminal arayüzünden ya da telefonundan izlersin, bitince bildirim gelir.

Neler yapar

Görevi ver, git

vmforai run dev "başarısız testleri düzelt": bir asistan arka planda tek başına çalışır.

Bir görev, birkaç deneme

vmforai try dev 3 "görev": VM'in saniyeler içinde üç kopyası, her biri görevi yapar; en iyisini alırsın.

Issue'dan pull request'e

vmforai fix dev 42 --test "npm test": asistan 42 numaralı issue üzerinde çalışır, testler VM'de çalışır, geçince bir PR açılır.

Kısa tasmalı ağ

vmforai net dev restricted: VM yalnızca listesindeki adreslere ulaşır; senin bilgisayarında uygulanır.

Telefondan

vmforai phone bir QR kod gösterir: VM'leri listele, asistanları bir terminalde aç, görev ver, bildirim al.

Beş asistan

Claude Code, Codex, Gemini CLI, OpenCode ve aider; ilk kullanımda kurulur.

Terminal arayüzü ve telefon

vmforai ui: VM oluştur, kabukları ve asistanları sekmelerde aç; anlık görüntüler, portlar, projeler.

vmforai phone: aynısı telefonun tarayıcısından.
